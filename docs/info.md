## Информация, Данные

1. Информация (от лат. informatio — "объяснение", "изложение") - это сведения об окружающем мире 
и происходящих в нём процессах, которые воспринимаются человеком (органами чувств) или техническим устройством.

2. Данные и информация представляют собой совокупность дискретных или непрерывных значений, 
которые могут описывать различные характеристики объектов и процессов: 
количество, качество, факты, статистические показатели и другие сведения.
Данные — это любая информация, представленная в таком виде, который удобен для 
автоматической обработки, хранения и передачи с использованием компьютерных технологий.

3. Цепочка: Данные, Информация, Знания
- Данные: сырые символы без контекста (38.5, 39.0).
- Информация: данные + смысл (температура пациента повышена).
- Знания: информация + опыт для решений (у пациента жар, нужно лечение).


## Классификация информации

Информацию можно разделить на виды по различным критериям:

- По значимости — важная, ценная, актуальная, достоверная
- По восприятию — визуальная, аудиальная, тактильная, обонятельная, вкусовая
- По форме — текстовая, числовая, графическая, аудио, видео
- По назначению — общедоступная, специализированная, секретная, личная
- По достоверности — истинная, ложная
- По объёму/масштабу — малая, средняя, большая, массивная

----------------------------------------------------

**По способу восприятия**

- Визуальная — воспринимаемая органами зрения.
- Звуковая — воспринимаемая органами слуха.
- Тактильная — воспринимаемая тактильными рецепторами.
- Обонятельная — воспринимаемая обонятельными рецепторами.
- Вкусовая — воспринимаемая вкусовыми рецепторами.

**По форме представления**

- Текстовая — передаваемая в виде символов, предназначенных обозначать лексемы языка.
- Числовая — в виде цифр и знаков (символов), обозначающих математические действия.
- Графическая — в виде изображений, предметов, графиков.
- Звуковая — устная или в виде записи и передачи лексем языка аудиальным путём.
- Видеоинформация — передаваемая в виде видеозаписи.

**По назначению**

- Массовая — содержит тривиальные сведения и оперирует набором понятий,
понятным большей части социума.
- Специальная — содержит специфический набор понятий, при использовании
происходит передача сведений, которые могут быть не понятны основной массе
социума, но необходимы и понятны в рамках узкой социальной группы, где
используется данная информация.
- Секретная — передаваемая узкому кругу лиц и по закрытым (защищённым и
адаптивным) каналам.
- Личная (приватная) — набор сведений о какой-либо личности, определяющий
социальное положение и типы социальных взаимодействий внутри популяции.

**По значению**

- Важная — информация, имеющая значительное влияние на принятие решений 
или последствия для деятельности субъекта.
- Ценная — полезность информации определяется субъектом, получившим
информацию в зависимости от объёма возможностей её использования.
- Актуальная — информация, ценная в данный момент времени.
- Достоверная — информация, полученная без искажений с надежных источников.
- Понятная — информация, выраженная на языке, понятном тому, кому она
предназначена.
- Полная — информация, достаточная для принятия правильного решения или
понимания.

**По истинности**

- Истинная.
- Ложная.
