## Алгоритмы и структуры данных

- Алгоритмы - последовательность действий для решения задач
- Структура данных - это способ форматирования данных, позволяющий системам эффективно обрабатывать и хранить данные
- Сортировка и поиск - фундаментальные механизмы упорядочивания жизни

**Структура данных**

- Строка
- Массив
- Список
- Связный список
- Множество
- Словарь/Хеш-таблица
- Дерево
- Граф
- Куча
- Стек (LIFO)
- Очередь (FIFO)

**Алгоритмы**

- Алгоритмы сортировки: Пузырьковая, Вставками и Быстрые (QuickSort, Слиянием).
- Алгоритмы поиска: Линейный и Бинарный.
- Арифметические алгоритмы: Математические алгоритмы, например, поиск Наибольшего Общего Делителя (алгоритм Евклида), 
возведение в степень или генерация простых чисел (Решето Эратосфена).
